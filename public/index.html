ℹ️ What is Duplicate Prevention? When enabled, the app checks your existing Google Calendar events and Tasks before adding new ones. If an entry with the same title already exists for that date, it skips it — preventing duplicates when you re-sync the same planner page. For Calendar events, it checks for the same title on the same date with the exact same start and end time.

📅 Calendar Duplicate Prevention Skips creating events that already exist at the same time on that date.
✅ Tasks Duplicate Prevention Skips creating tasks that already exist with the same name on that date.
