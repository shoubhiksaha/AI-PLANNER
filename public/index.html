Notion Setup Guide


            

                

                    
Step 1: Get Access Token

                    
    
                        
  1. Go to notion.so/my-integrations.
    2. 
                        
  2. Click + New integration (or open your existing AI Planner connection).
    3. 
                        
  3. Name it "AI Planner" and submit.
    4. 
                        
  4. Open Manage connection and copy the Access token
                            (ntn_... on new connections, or legacy secret_...).
    5. 
                    

                


                

                    
Step 2: Create Your Journal Database

                    
    
                        
  1. Open Notion and create a new empty page.
    2. 
                        
  2. Type /database and select "Database - Full page".
    3. 
                        
  3. Name it "Brain Dump Journal".
    4. 
                    

                


                

                    
Step 3: Connect AI Planner

                    
    
                        
  1. Stay on your new Database page.
    2. 
                        
  2. Click the ... (three dots) at the very top-right of the Notion window.
    3. 
                        
  3. Scroll down to "Connections" > "Connect to".
    4. 
                        
  4. Search for "AI Planner" and select it. Confirm access.
    5. 
                    

                


                

                    
Step 4: Copy the Database Link

                    
    
                        
  • Click Share → Copy link (or copy the address bar). It looks like:
    • 
                        
  • https://www.notion.so/395c...38ab?v=...
    • 
                        
  • Paste the whole link — AI Planner picks out the 32-character database ID for you.
