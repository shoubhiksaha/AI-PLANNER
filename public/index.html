Notion Setup Guide

Step 1: Get Access Key

  1. Go to notion.so/my-integrations.
  2. Click + New integration.
  3. Name it "AI Planner" and submit.
  4. Copy the "Internal Integration Secret" (Key).

Step 2: Create Your Journal Page

  1. Open Notion and create a new empty page.
  2. Type /database and select "Database - Full page".
  3. Name it "Brain Dump Journal".

Step 3: Connect AI Planner

  1. Stay on your new Database page.
  2. Click the ... (three dots) at the very top-right of the Notion window.
  3. Scroll down to "Connections" > "Connect to".
  4. Search for "AI Planner" and select it. Confirm access.

Step 4: Get Database ID

  • Look at the URL of your database page:
  • https://notion.so/myworkspace/18b3...4d92?v=...
  • Copy the 32-character code between the slash / and the question mark ?.
  • If there is no question mark, copy the ID at the end.
