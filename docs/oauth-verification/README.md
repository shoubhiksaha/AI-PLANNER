# OAuth Verification Pack

This folder contains the exact artifacts you need for Google OAuth app verification.

## Files

- `scope-justification.md`: Copy-paste text for requested scopes and least-privilege reasoning.
- `demo-video-script.md`: Step-by-step recording script for the reviewer demo video.
- `test-account.md`: Reviewer test account setup template and handoff checklist.
- `submission-checklist.md`: Final pre-submit checklist for consent screen + domain + policies.
- `brand-verification-form-template.md`: Ready-to-paste branding form text and documentation links template.

## How to use

1. Fill placeholders in `test-account.md`.
2. Record your video using `demo-video-script.md`.
3. Paste scope text from `scope-justification.md` into OAuth verification form.
4. Confirm all checks in `submission-checklist.md`.
