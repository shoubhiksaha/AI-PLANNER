# Brand Verification Form Template (Copy/Paste)

Use this template when submitting in Google Auth Platform -> Verification Center.

## 1) Branding fields

### Application name

`AI Planner`

### User support email

`<support@yourdomain.com>`

### App logo

Upload your production logo (optional but recommended).

### Authorized domains

Add only top private domains you own and have verified in Search Console (examples):

- `yourdomain.com`
- `app.yourdomain.com`

Note: Prefer your own custom domain for production trust and smoother review. Avoid shared platform domains in production verification submissions whenever possible.

### Application home page

`https://yourdomain.com/`

### Privacy policy URL

`https://yourdomain.com/privacy`

### Terms of service URL (optional)

`https://yourdomain.com/terms`

### Developer contact emails

- `<founder@yourdomain.com>`
- `<ops@yourdomain.com>`

## 2) Text to use in "Additional information"

```text
AI Planner is a productivity app that helps users convert planner pages into actionable items and sync them to Google services.

The OAuth consent screen branding (app name, support email, homepage, privacy policy, and authorized domains) matches our production identity.

Our homepage and privacy policy are publicly accessible on the same verified domain and clearly describe how Google user data is accessed, used, and controlled by the user.
```

## 3) Up to 3 documentation links to provide

Use public links on your verified domain:

1. Feature overview page:
   - `https://yourdomain.com/` (section explaining Google integrations)
2. Privacy policy:
   - `https://yourdomain.com/privacy`
3. Scope usage details page:
   - `https://yourdomain.com/oauth-scopes` (or equivalent public doc page)

If you do not have a dedicated scope page yet, publish one first.

## 4) If prompted for sensitive-scope details

Brand verification and sensitive-scope verification are often part of one review flow.

Be ready with:

- Per-scope justification text:
  - see `scope-justification.md`
- Demo video URL (unlisted):
  - see `demo-video-script.md`
- Reviewer test account:
  - see `test-account.md`

## 5) Final pre-submit checks

- Homepage and privacy policy are publicly accessible without login.
- Domain ownership is verified in Search Console for all authorized domains.
- Consent screen values exactly match production branding.
- Support/developer emails are monitored during review.
